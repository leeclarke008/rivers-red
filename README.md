# riversred.com (Version 1.0)





### Overview



riversred.com is the official website for the Newcastle Upon Tyne-based rock band Rivers Red. Formed in August 2026, the band currently consists of lead vocalist/keyboardist Lee Stuart Clarke and guitarist Alex Avery.



This website serves as a central hub for all content related to the band - music releases, information on members and band history, photos/videos, news and social media updates.





### Pages



* **Home** - the default page of the website. Will feature easily digestible text, visuals and links to other pages.
* **The Band** - an overview of the band and its history, including individual profiles of each band member.
* **Music** - a catalogue of past and upcoming music releases by the band, including detailed artwork, liner notes and free short previews of select songs.
* **Gallery** - an extensive collection of photographs, videos and other related content.
* **Contact** - a contact form for general enquiries. Will likely be expanded greatly as the band grows in popularity.





### Tech Stack



* HTML5
* CSS3
* JavaScript
* GitHub Pages





### Running Locally



Clone the repository and open index.html in a browser.
